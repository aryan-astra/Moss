# Getting comfortable with Moss

**Start:** exit any old copy, extract the entire application ZIP, then open Moss.exe. Your pet and its separate control window should appear on a normal desktop. Windows fullscreen/presentation settings can intentionally hide the creature.

**Meet another companion:** open Customize and choose Moss, Miso, Pip, Lark, Inky, Clover or Puck. Only one is active. Pet names and sizes are changed under Pet. Names save when you leave the name field.

**Play:** rub across the head a few times, or grab the body and move it. Release gently to drop; release during a fast movement to throw. The little twig toy can also be pulled away and thrown. The book opens your notebook.

**Write:** click + or press Ctrl+N and type normally. Ctrl+B/I/U formats text; right-click holds editing commands. The first line labels the note. The small left rail identifies pages. There is no document toolbar or file menu. Autosave waits about 700 ms after typing; Ctrl+S saves now. Esc closes. Notes stay global when pets change.

**Remember something:** on a note line type `@remind tomorrow 9am call home`, then press Ctrl+Enter. Check the exact date/time/message in the confirmation. To set a timer, try `@timer 25m`. The shell's Notebook area shows remaining time and lets you snooze, dismiss or cancel.

**While the app is closed:** opt in under Notebook if you want Windows to launch Moss for reminders. The status tells you whether task registration succeeded. This needs an available signed-in Windows session and is not guaranteed to run at the exact second after sleep/offline time. Keep the installed EXE in the same folder.

**Keep things quiet:** use Sounds → Off, Behavior → Calm, or Reduced motion under Pet/Behavior. Ctrl+Shift+F12 toggles quiet mode. The tray always provides Show/recover, Hide and Exit.

**Privacy:** no accounts, cloud AI, screen capture, clipboard reading, microphone recording or browser-history access. Music metadata and local speaker-output analysis are separate opt-ins. Incoming Windows notification observation requires the optional signed installation, not the portable ZIP.

**Protect your pages:** settings, notes and logs live in `%LOCALAPPDATA%\Moss`. Back up that folder. If a page reports an unsaved error, keep it open and select and copy the text to a safe local document. Do not delete the notebook folder to reset the pet.

**Exit:** use the tray's Exit Moss. Closing the shell does not exit. **Uninstall:** exit, remove Moss startup/reminder tasks with the included uninstall script if used, and delete the application folder. The script keeps your local data unless you explicitly request deletion.

This build has substantive implemented features, but it is not the fully accepted production product requested in the master specification. Read ACCEPTANCE.md before treating animation quality, native integration or reminder delivery as certified.

## New interactions in 1.3

Click the headphones/player during dance, or tray → Now playing, to open the small music card. Enable details there to see player-supplied metadata/artwork/timeline. Unidentified audio never receives a made-up title.

Settings → Browser/audio fallback controls default-output levels only; it does not record audio. It is enabled by default with media awareness and can also notice other sustained sound. Behavior controls rare music compliments and occasional football play. Pet → Roll a football starts a ball explicitly.

Slowly pull/lift the twig to keep the grip; sharp pulls and repeated shocks can release it. Petting now shows hearts. Music can cause small physical hops unless reduced motion/calm mode is active. Main preferences also have Save changes; note autosave is unchanged.
